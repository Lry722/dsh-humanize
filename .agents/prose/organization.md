# Rules

1. 一段话不要写太长，应该把前后关系梳理清楚，局部只专注于一个话题。但也不能把完整的内容拆太碎，要控制合适的段落长度。
2. 对于过程性描述，应当将其自然融入整体。不要和废弃的内容做对比，只保留现状。
3. 不要将技术细节混入整体设计，确保读整体设计时思路连贯。注意不要因此丢弃技术细节，应当将其放到合适的位置。
4. 一节不要太多段落，注意分节。一节内容太多，或是段落太多时考虑调整文章结构。

# 补充说明

涉及到违反组织结构的写法，允许大段重写，不要束手束脚只改局部。
