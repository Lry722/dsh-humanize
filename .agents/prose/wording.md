# Rules

1. 严禁滥用否定句，例如 “不影响”、“不进入”、“不是…而是…” 这类说法。
2. 严禁滥用形容词，例如 “可读”、“可审查”、“天然” 这类词。
3. 适当口语化，不要为了追求简洁而使用过于简短的词汇。

# 说明

滥用是指频次过高和非必要使用。也就是存在更好的表达方案，且不会损失有意义的信息，也不改变要表达的含义。

例如，若否定句是用于方案对比，则是有意义的。而若是强行否定一个和事实无关的假设，则没有意义。

若修改后没有明显更好，则不用强行修改。
