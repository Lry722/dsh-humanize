# Rules

1. 注意保持平铺直叙的风格，严禁滥用括号和长难句。
2. 合理断句，严禁滥用逗号和句号外的符号，例如分号、破折号。

# 说明

滥用是指频次过高和非必要使用。也就是存在更好的表达方案，且不会损失有意义的信息，也不改变要表达的含义。

例如，若简单说明某个东西的别称，用括号是合理的。而在括号中放一段解释性长句子，就不太不合理。

若修改后没有明显更好，则不用强行修改。
